# Expense Tracker

An Android Expense Tracker application built using modern Android development practices.

## 📱 Features

* Add and manage expenses
* Store expenses locally
* View expense records
* MVVM architecture

## 🛠️ Tech Stack

* **Kotlin**
* **MVVM**
* **Room Database**
* **Hilt**
* **Kotlin Coroutines**
* **Jetpack Components**
* **XML / Android Views**

## 🏗️ Architecture

```text
UI
 ↓
ViewModel
 ↓
Repository
 ↓
Room Database
```
