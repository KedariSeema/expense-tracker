# \# Expense Tracker

# 

# An Android Expense Tracker application built as a hands-on project to demonstrate modern Android development practices, Jetpack components, MVVM architecture, and clean code organization.

# 

# \## 📱 Features

# 

# \* Add and manage expenses

# \* View expense records

# \* Store expense data locally

# \* MVVM architecture

# \* Room Database for local persistence

# \* Hilt for dependency injection

# \* Kotlin Coroutines for asynchronous operations

# \* Jetpack components

# \* Clean and maintainable project structure

# 

# \## 🛠️ Tech Stack

# 

# \* \*\*Language:\*\* Kotlin

# \* \*\*Architecture:\*\* MVVM

# \* \*\*UI:\*\* Android Views / XML

# \* \*\*Database:\*\* Room

# \* \*\*Dependency Injection:\*\* Hilt

# \* \*\*Asynchronous Programming:\*\* Kotlin Coroutines

# \* \*\*Build System:\*\* Gradle

# \* \*\*Minimum SDK:\*\* 24

# 

# \## 🏗️ Architecture

# 

# The application follows the MVVM architecture:

# 

# ```text

# UI

# &#x20;↓

# ViewModel

# &#x20;↓

# Repository

# &#x20;↓

# Room Database

# ```

# 

# \### Main Components

# 

# \* \*\*UI:\*\* Displays expense information and handles user interactions.

# \* \*\*ViewModel:\*\* Manages UI-related data and application state.

# \* \*\*Repository:\*\* Acts as the abstraction layer between the ViewModel and data source.

# \* \*\*Room Database:\*\* Provides local data persistence.
